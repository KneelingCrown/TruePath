## Повторная сборка

Нужны Python 3, `python-pptx`, `reportlab`, `Pillow` и шрифты DejaVu Sans / Serif в `/usr/share/fonts/truetype/dejavu/`.

```bash
python3 presentation/build.py
```

Скрипт создаёт оба формата и заметки. Текст и схемы в PPTX редактируются. PDF строится из тех же координат и переносов. После ручных изменений PPTX сборка их перезапишет — сохраняйте отдельную версию или меняйте исходный скрипт. Из-за различий шрифтов в PowerPoint перед выступлением проверьте файл на целевом компьютере; PDF сохраняет встроенные шрифты.
