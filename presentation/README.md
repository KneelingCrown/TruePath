## Что изменено

Прежние повторяющиеся карточки заменены отдельными композициями: крупные заголовки, светлые, тёмные и мятные развороты, минимальные схемы и большие снимки приложения. Текст сокращён и перенесён в заметки. Сюжет: учебная новость о бесплатном транспорте → условия обещания → основания → сохранённое понимание.

Основной PPTX содержит страницы PDF, отрисованные в 2400 × 1350 пикселей, поэтому при открытии не зависит от установленных шрифтов и не меняет переносы. Его страницы не редактируются как отдельные текстовые поля. Для правок есть `TruePath-editable.pptx` и исходный `build.py`. У редактируемого файла переносимость шрифтов зависит от компьютера; финальный вариант сверять с PDF.

## Достоверность содержания

Память, усвоение и адаптация помечены как следующие этапы. Использованы настоящие светлые Compose-снимки репозитория; это эталоны Paparazzi, не фотографии телефона. Тёмные снимки из чата задали палитру, но оригиналы не доступны как локальные файлы и не включены в экспорт. [Происхождение медиа](../docs/ASSET_CREDITS.md).

Проверка на слайде 9 привязана к коду `47f97e4`: локально пройдены 16 unit-тестов и компиляция; Lint — 0 ошибок, 6 предупреждений. Это не статус GitHub Actions, не проверка жестов на устройстве и не доказательство качества фактчекинга. Перед защитой обновить статус по текущей реализации. Образовательный эффект ещё предстоит измерить.

## Сборка

Python 3: `python-pptx`, `reportlab`, `Pillow`. Системные зависимости: `pdftoppm` и шрифты Liberation в `/usr/share/fonts/truetype/liberation/`.

```bash
python3 presentation/build.py
```

Сборка создаёт PDF, оба PPTX и заметки. Размер строк проверяется по реальным метрикам шрифта. Финальные страницы PDF нужно просмотреть перед публикацией. Ручные изменения PPTX скрипт перезапишет; правьте исходник или сохраняйте отдельную копию.
